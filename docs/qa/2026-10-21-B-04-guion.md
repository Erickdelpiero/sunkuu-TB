- El script aborta en estos casos:
  - falta un widget o alguno está en el bundle "Sunkuu";
  - el módulo no está declarado en el editor JavaScript, o su alias o su referencia son otros;

**3.7 Forma en que ThingsBoard guarda la referencia.** Con un módulo declarado, `descriptor.controllerScript` deja de ser texto y pasa a ser un objeto:
```
"controllerScript": { "body": "<JS del widget>", "modules": { "registroMod": "tb-resource;/api/resource/js_module/tenant/sunkuu-registro.js" } }
```
- La clave es `modules`, dentro de `controllerScript`, no `resources`. La referencia usa la forma `tb-resource;<link>` y la clave del objeto es el alias.
